# Random Words ✦

Offline-first Android app for creative writing challenges.

The app gives random words from a local dictionary and asks the writer to turn them into a coherent text. A pause longer than the selected limit destroys the current text and forces a restart.

## Features
- 40 built-in nouns plus TXT import.
- 1 / 2 / 3 / 5 / 7 / 10 random words.
- Goals: 100 / 200 / 300 words, 2 / 5 / 10 minutes, or endless.
- 6 / 5 / 4 / 3 second inactivity difficulty.
- Blind mode, Chaos, Word Boss and repeat-set modes.
- Required-word validation.
- Score, streak, record and achievements.
- Local library with titles, notes and folders.
- No server, account or required internet.
- GitHub Actions APK build.

## Build
Open in Android Studio or run the GitHub Actions workflow "Build APK".
